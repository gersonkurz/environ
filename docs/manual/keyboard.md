# Keyboard shortcuts

[← Back to contents](index.md)

## Global & navigation

| Shortcut | Action |
| --- | --- |
| `Ctrl+F` | Focus the Filter box (`Esc` clears filter and returns to grid) |
| `Ctrl+S` | Open the dry-run **Review Changes** dialog |
| `Ctrl+H` | Open the **Snapshot History** dialog |
| `F5` | Reload variables from the registry |
| `Ctrl+C` | Copy selected variable(s) (`NAME=value`) or path segment(s) |
| `Ctrl++` / `Ctrl+Wheel Up` | Zoom in (+10%) |
| `Ctrl+-` / `Ctrl+Wheel Down` | Zoom out (-10%) |
| `Ctrl+0` | Reset zoom to 100% |
| `Shift+Wheel` | Scroll the `VALUE` column horizontally (keeping `NAME` frozen) |
| `Alt+F4` | Exit Environ |

## Inline editing & structure

| Shortcut | Action |
| --- | --- |
| `F2` or double-click value | Edit the selected cell's value in place |
| Double-click name | Rename the selected variable in place |
| `Enter` | Commit the active inline edit |
| `Esc` | Cancel the active inline edit |
| `Tab` / `Shift+Tab` | Commit and jump to the next / previous editable cell |
| `Ins` | Insert a new path-list entry (on a path list) or create a new variable (on a scalar) |
| `Del` | Remove the selected path-list entry or delete the selected variable |
| `Alt+↑` / `Alt+↓` | Move the selected path-list entry up or down within its variable |

## Dialogs

| Shortcut | Action |
| --- | --- |
| `A`–`Z` (in Font dialog) | Jump to font families starting with that letter |
| `Enter` | Apply / confirm dialog |
| `Esc` | Cancel / close dialog (reverts live theme or font preview) |
